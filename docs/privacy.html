飞马相册（包名 com.jonas.fmphoto）由个人开发者皮朝猛开发，是面向飞牛 NAS 相册的非官方 HarmonyOS 客户端，用于在你指定的 NAS 上登录、浏览、搜索、预览、上传、下载和管理相册。开发者不运营自己的云端相册服务，不包含广告、第三方统计或崩溃上报 SDK，也不会把你的照片、账号或密码发送到开发者服务器。若使用 FN ID 或官方中继，应用会向飞牛 FN Connect（fnos.net / 5ddd.com）解析地址，登录和相册流量可能经其中继转发到你的 NAS。

我们处理哪些信息

为实现相册客户端功能，应用会在设备本地、用户配置的 NAS，以及（仅当使用 FN ID / 官方中继时）飞牛 FN Connect 之间处理以下信息：

  • NAS 连接信息：你输入的服务器地址、协议、账号名、FN ID、公网域名、选路偏好、相册父目录等。
  • 登录凭据和会话信息：NAS 密码、登录后获得的 token / 长 token、WebSocket 签名密钥、OpenAPI Authx key/secret、受信任证书主机列表。上述信息保存在应用私有存储中，用于会话保持、冷启动恢复和登录表单回填。
  • 记住密码（可选）：若你开启「记住密码」，密码会经系统 HUKS（AES-256-GCM）加密后仅保存在本机，密钥不出应用沙箱。退出登录时，若仍开启该选项，加密后的密码会保留以便下次回填；关闭该选项或清除应用数据后即删除。
  • 本机设备标识：应用会生成并保存一个 WebSocket 设备标识（did），用于飞牛登录和两步验证「信任本设备」。该标识不是 IMEI、OAID 或硬件序列号，退出登录时默认保留。
  • 相册数据：从 NAS 返回的照片、视频、缩略图、原图地址、文件名、大小、拍摄时间、收藏、回收站、人物 / 分类 / 搜索结果等。
  • 媒体元数据：详情或地图可能展示 NAS 返回的相机型号、曝光、文件路径、经纬度、地点聚合等。
  • 用户选择的本地媒体：你主动上传时，应用通过系统图片选择器读取所选文件并发送到你的 NAS。公开发布包不申请读取本机相册权限，也不会在未经你操作时扫描媒体库。
  • 配置同步（可选）：二维码在本机展示或扫描；若你填写 WebDAV 地址，相关配置（可能含登录信息）会发往该地址。
  • 本地临时文件：下载、预览、保存到系统相册等可能在缓存目录创建临时文件，完成后会尽量清理。
  • 运行日志：可能记录连接状态、请求结果、错误摘要、主机地址或文件名。不以收集隐私为目的记录密码或完整 cookie；分享日志前请自行检查。

信息如何使用

  • 连接你指定的 NAS，完成登录、会话恢复和接口签名。
  • 展示相册首页、时间线、分类、人物、搜索、地图、详情和预览。
  • 执行你主动发起的上传、下载、保存、收藏、删除、恢复等操作。
  • 在上传或下载时维持短时间后台传输。
  • 记住登录表单、证书信任和可选的加密密码，减少重复输入。

数据发送到哪里

默认传输目标是你在登录页确认的 NAS 及其相册接口。开发者不会通过本应用接收、存储或转售你的照片、视频、账号、密码、token 或其他个人信息。

若你填写 FN ID 或使用飞牛官方中继，应用会向 https://fnos.net/api/v1/fn/con 提交 FN ID 以解析公网 / 内网 / 中继地址；此后登录和相册请求可能经 *.fnos.net 或 *.5ddd.com 加密转发到你的 NAS。该服务由广州铁刃智造技术有限公司运营，详见 第三方共享个人信息清单 及飞牛官方政策。仅填写局域网或公网直连地址时，不会请求飞牛云解析。

若你填写公网域名、反代或自行配置的 WebDAV 地址，相关数据会发往该地址，其安全与日志策略由你或对应服务方负责。

系统权限说明

  • 网络访问：连接 NAS、加载媒体和接口请求；使用 FN ID 时访问飞牛云。
  • 获取网络状态：判断连接状态，辅助请求和错误提示。
  • 后台运行 / 数据传输：你主动上传或下载时维持短时间后台任务。
  • 振动：长按、多选等交互反馈。
  • 系统图片选择器和保存到相册：由你主动选图上传，或把 NAS 中的内容保存到系统相册。不申请读取本机相册权限。

定位和地图

应用不申请设备定位权限，也不读取设备实时位置。地图使用 NAS 返回的照片地理元数据。内置网页地图已关闭网页地理定位。

保存、查阅与删除

会话 token、签名密钥、账号、服务器地址、证书信任列表、设备标识和部分设置保存在本机应用私有存储。退出登录会清除主要会话 token 和签名凭据；账号、FN ID、域名和选路等表单会保留。记住密码开启时，加密密码也会保留。

NAS 上的照片、分类、回收站等由你的 NAS 管理，应用内删除 / 恢复 / 上传会直接作用于该 NAS。

你可在本页及 已收集个人信息清单、第三方共享个人信息清单 查阅处理情况；可在登录页更正连接信息；可关闭记住密码、退出登录、在系统设置中清除应用数据或卸载以删除本机信息。撤回同意后将退出应用，再次打开需重新同意。

安全说明

应用支持 HTTPS 连接 NAS。自签名或无法校验的证书，仅在你明确选择信任后才会加入本机受信任列表。请确认 NAS 地址、证书和网络环境可信后再输入账号密码。

儿童隐私

本应用不是面向不满十四周岁儿童的服务，也不会主动识别或分析儿童个人信息。相册中是否包含相关内容，取决于你自己的 NAS 使用方式。
